# دفاتر المحاسب — نظام إدارة مكتب المحاسبة والمراجعة المتكامل

نظام محلي متكامل لإدارة مكتب المحاسبة والمراجعة، مبني ليعمل على جهاز مكتبك مباشرة:

- **إدارة مكتب المحاسبة**: شركات العملاء والمنشآت الفردية، كل شركة بملفها الضريبي الكامل بمواعيد التجديد، الالتزامات الضريبية بمواعيدها القانونية، المهام المُسندة للزملاء، ولوحة السكرتارية.
- **الشق المالي والمحاسبي**: فواتير البيع والشراء، العملاء والموردون، المخزون، الخزائن والبنوك، قيود اليومية ودليل الحسابات، الأصول الثابتة والإهلاك، الموظفون والرواتب، الموازنات، التقارير المالية والضرائب المصرية.
- **الأمان وحماية الجلسات**: حماية الخادم عبر بوابة Next.js Middleware (`src/middleware.ts`) والتحقق الموثوق من التوقيع الرقمي والصلاحيات على مستوى الأدوار (`admin`, `accountant`, `viewer`).

## خطوات التشغيل

1. تثبيت الحزم: `npm install`
2. تهيئة قاعدة البيانات: `npm run db:push && npm run db:init`
3. تشغيل وضع التطوير: `npm run dev`
